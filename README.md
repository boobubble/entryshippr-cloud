# Entryshippr Cloud

Build EntrySetu — Your Business Entry & Billing Bridge as a complete, production-ready courier entry and billing SaaS.

Use Lovable Cloud for the backend and hosting, and my own Razorpay merchant account for payments.

Implement real signup/login, 5-day free trial, Excel processing, shipments, client management, rate cards, GST/Non-GST invoicing, dashboards, subscriptions, and super admin.

Pricing:

Standard: ₹1,200/year, up to 50 active clients.

Standard Unlimited: ₹1,800/year, 50+ active clients.

One-time joining fee: ₹3,000 on first paid purchase.

Use secure multi-tenant data isolation. No mock data or nonfunctional buttons.

Reuse the design of my previous EntrySetu project if accessible.

Build, test, and publish as quickly as possible. Avoid unnecessary phases and explanations. Use Razorpay Test Mode before Live Mode.

Do not modify my existing entrysetu.in website or production database.
